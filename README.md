# Кулинарная соцсеть — Мобильное приложение

## Project Name
**Кулинарная соцсеть** — мобильный клиент.

## Description
Мобильное приложение социальной сети для публикации и поиска рецептов. Оптимизировано под смартфоны (портретная ориентация, диагонали 5.5″–6.7″). Поддерживает сенсорное управление, жесты (свайпы для переключения шагов, pull-to-refresh, pinch-to-zoom), камеру для съёмки видео-рецептов и фотоотчётов, push-уведомления, офлайн-режим и режим Wake Lock для готовки.

## Installation
На данный момент проект находится на стадии проектирования. Инструкция будет добавлена после реализации.

Планируемые шаги:
1. Клонировать репозиторий: `git clone https://github.com/katekasyanik/zvaniy_yuzin-mobile.git`
2. Установить зависимости: `flutter pub get` (или `npm install` для React Native).
3. Запустить на эмуляторе или устройстве.

## Usage
Мобильное приложение позволит:
- Искать рецепты по ингредиентам с исключением аллергенов.
- Пересчитывать порции и генерировать список покупок.
- Публиковать видео-рецепты и фотоотчёты.
- Использовать режим пошаговой готовки с Wake Lock и таймерами.
- Работать офлайн с сохранёнными рецептами.
